# Dev-Microverse

A structured collection of 500+ Frontend Micro Programs built using JavaScript, React, and Next.js.

## Purpose

This repository is created to master frontend development through small, focused programs.

Each program demonstrates a single concept, making it useful for learning, revision, and technical interview preparation.

## Topics

- JavaScript
- Browser APIs
- IndexedDB
- LocalStorage
- SessionStorage
- Cookies
- Fetch API
- DOM
- Events
- Promises
- Async / Await
- React
- Next.js

## Getting Started

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open your browser

```text
http://localhost:3000
```
